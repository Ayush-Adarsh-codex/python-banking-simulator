# python-banking-simulator
A lightweight, command-line banking application built in Python that simulates basic account operations like deposits, withdrawals, and KYC document management.

# Features

* **Account Balance Management:** Check your current balance in real-time.
* **Deposits & Withdrawals:** Safely add funds to your account or withdraw them, complete with basic validation to prevent overdrafts or invalid amounts.
* **KYC Integration:** Add, store, and view essential identity documents (e.g., Passport, PAN, SSN) directly within the application.
* **Interactive Menu:** A user-friendly, loop-based menu system that keeps the application running until you choose to exit.

# Prerequisites

To run this application, you only need Python installed on your system.
* Python 3.6 or higher
